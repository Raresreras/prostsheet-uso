#### REGEX RULES ####

^ - start of string

$ - end of string

. - any character except newline

\d - any digit 0–9

\D - any non-digit character

\w - word character (letter/digit/underscore)

\W - non-word character

\s - whitespace character

\S - non-whitespace character

[abc] - any listed character

[^abc] - any character except listed

[a-z] - character range

* - zero or more

+ - one or more

? - zero or one

{n} - exactly n times

{n,} - n or more times

{n,m} - between n and m

() - capture grouped pattern

(?: ) - non-capturing group

| - OR / alternation

\ - escape special character

\b - word boundary

\B - non-word boundary



#### SPECIAL REGEX ####

\b\w{1,3}\b - cauta cuvinte cu caractere intre 1 si 3

\b(\w+)\s+\1\b - gaseste cuvinte care se repeta
